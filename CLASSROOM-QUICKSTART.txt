Studyvillage 교실 실행 안내
===========================

1. Studyvillage portable EXE를 더블클릭합니다.
2. 잠시 후 학생 접속 QR 화면이 자동으로 열립니다.
3. 화면의 ⭐ 학생용 추천 QR을 학생 패드 한 대에서 먼저 시험합니다.
4. 접속되면 학생은 이름 + 비밀번호로 입장합니다.
5. 교사는 QR 화면의 관리자 화면 버튼으로 학생 기록을 관리합니다.
6. 추천 QR이 열리지 않을 때만 “다른 접속 주소 보기”를 펼쳐 대체 QR을 시험합니다.

수업 전 1대 시험
---------------
수업 시작 전에 학생 패드 한 대로 QR 접속 → 로그인 → 활동 저장까지 한 번 확인하는 것을 권장합니다.
한 대에서 정상 동작을 확인한 뒤 전체 학생을 입장시키면 네트워크 문제를 미리 발견하기 쉽습니다.

앱 실행이 이상할 때
------------------
Studyvillage를 실수로 두 번 실행해도 교실 서버는 하나만 유지됩니다.
앱이 시작되지 않고 오류 안내가 뜨면 Studyvillage 창을 모두 닫고 다시 실행하세요.
계속 시작되지 않으면 선생님이 직접 Windows에서 컴퓨터를 재부팅한 뒤 다시 실행해 보세요.
Studyvillage가 컴퓨터를 자동으로 종료하거나 재부팅하지는 않습니다.

초기 관리자 비밀번호
--------------------
teacher1234

첫 로그인 후 반드시 변경하세요.

학생 데이터 저장
----------------
학생 계정과 점수는 EXE 파일 안이 아니라 Windows 사용자 데이터 폴더에 저장됩니다.
따라서 Studyvillage EXE를 새 버전으로 교체해도 학생 기록은 유지되도록 설계되어 있습니다.
관리자 화면의 백업 기능을 이용하면 다른 PC로 이동할 수도 있습니다.

네트워크
--------
교사 PC와 학생 패드는 서로 통신 가능한 같은 학교 내부망에 있어야 합니다.
교사 PC가 유선 LAN이고 학생 패드가 Wi-Fi여도 정상적인 구성입니다.
중요한 것은 학교 유선망과 Wi-Fi망 사이에서 기기끼리 통신할 수 있는지입니다.
QR 화면은 사용 가능한 주소 중 가능성이 높은 주소 하나를 ⭐ 학생용 추천 QR로 먼저 보여줍니다.
추천 QR이 열리지 않으면 “다른 접속 주소 보기”를 펼쳐 대체 주소를 시험하세요.
학교 게스트망이나 분리망처럼 기기간 통신을 막는 환경에서는 접속되지 않을 수 있습니다.

Windows 보안 경고
-----------------
현재 개발 빌드는 코드 서명이 없는 실행 파일이므로 Windows SmartScreen 경고가 표시될 수 있습니다.
실제 사용 전에는 파일 출처가 본인의 Studyvillage GitHub 빌드인지 확인하세요.
앱 첫 실행 때 Windows 방화벽의 네트워크 접근 허용 창이 뜨면 사설 네트워크 접근을 허용합니다.

종료
----
Studyvillage 창을 닫으면 교실 서버도 함께 종료됩니다.
