# 🌳 우리 학습마을 (Studyvillage)

교실에서 사용할 수 있는 학습 RPG 프로젝트입니다.

## 현재 버전

**v0.2.7 — Personal Record Board**

- 이름별 플레이어 프로필
- 수수께끼 객관식 10문제
- 문제당 100점, 최대 1000점
- 누적 점수 / 도전 횟수 / 최고 점수 / 최근 점수 기록
- HUD의 `내 기록` 버튼
- 개인 기록판에서 4가지 기록을 한눈에 확인
- 퀴즈 종료 후 바로 개인 기록판으로 이동
- 같은 기기/브라우저에서는 이름별 기록 임시 저장(localStorage)
- 기존 이동, 충돌, NPC, 도전관 기능 유지

## 기록 구조

현재는 브라우저의 `localStorage`를 사용합니다.

- `totalScore`: 누적 점수
- `attempts`: 퀴즈 완료 횟수
- `bestScore`: 최고 점수
- `lastScore`: 최근 점수
- `updatedAt`: 마지막 기록 시각

이후 온라인 데이터베이스에서 참여 횟수, 출석, 정답률, 경험치 등을 추가하기 쉬운 구조로 확장할 예정입니다.

## 실행 상태

현재 소스는 정적 웹앱 형태입니다. 실제 접속 가능한 배포 경로가 확보되는 순간 별도로 안내합니다.
