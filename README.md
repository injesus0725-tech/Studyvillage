# 🌳 우리 학습마을 (Studyvillage)

교실에서 사용할 수 있는 학습 RPG 프로젝트입니다.

## 현재 버전

**v0.2.6 — Ten Question Records**

- 시작 전 이름 입력
- 이름별 플레이어 프로필
- 수수께끼 객관식 10문제
- 문제당 100점, 최대 1000점
- 누적 점수 기록
- 도전 횟수 기록
- 최고 점수 기록
- 최근 점수 기록
- 같은 기기/브라우저에서는 이름별 기록 임시 저장(localStorage)
- 도우미 선생님이 현재 도전 횟수와 최고 점수를 안내
- 기존 이동, 충돌, NPC, 도전관 기능 유지

## 기록 구조

현재는 브라우저의 `localStorage`를 사용합니다. 이름별로 다음 항목을 저장합니다.

- `totalScore`: 누적 점수
- `attempts`: 퀴즈 완료 횟수
- `bestScore`: 최고 점수
- `lastScore`: 최근 점수
- `updatedAt`: 마지막 기록 시각

이 구조는 이후 온라인 데이터베이스로 옮길 때 확장하기 쉽도록 구성했습니다. 참여 횟수, 출석, 정답률, 경험치 등의 항목도 이후 추가할 수 있습니다.

## 실행 상태

현재 소스 구조는 정적 웹앱 형태이며 `index.html`, `style.css`, `game.js`로 구성됩니다.
실행 확인 경로가 준비되는 즉시 별도로 안내합니다.
