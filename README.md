# 🌳 우리 학습마을 (Studyvillage)

교실에서 사용할 수 있는 학습 RPG 프로젝트입니다.

## 현재 버전

**v0.2.5 — Player Profile**

- 시작 전 이름 입력
- 이름 없이는 입장 불가
- 캐릭터 머리 위 이름 표시
- HUD 플레이어 프로필 표시
- 도우미 선생님이 플레이어 이름을 불러주는 대화
- 도전관 퀴즈 점수 누적
- 같은 기기/브라우저에서는 이름별 누적 점수 임시 저장(localStorage)
- 기존 이동, 충돌, NPC, 퀴즈 기능 유지

## 실행 상태

현재 소스 구조는 정적 웹앱 형태이며 `index.html`, `style.css`, `game.js`로 구성됩니다.
실행 확인 경로가 준비되는 즉시 별도로 안내합니다.
