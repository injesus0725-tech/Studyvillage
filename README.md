# 🌳 우리 학습마을 (Studyvillage)

교실에서 사용할 수 있는 학습 RPG 프로젝트입니다.

## 현재 버전

**v0.2.2 — Collision Update**

- 시작 화면
- 학습마을 광장
- 플레이어 캐릭터
- 방향키 / WASD 이동
- 모바일 화면용 방향 버튼
- PC와 태블릿 브라우저 대응
- 화면 경계 충돌
- 건물, 나무, 연못 충돌

## 실행 방법

`index.html`을 웹 브라우저로 열면 바로 실행됩니다.

> 일부 브라우저 환경에서는 GitHub에서 파일을 내려받은 뒤 `index.html`을 더블클릭하면 됩니다.

## 개발 원칙

각 버전은 가능한 한 직접 실행하고 테스트할 수 있는 상태를 유지합니다.
