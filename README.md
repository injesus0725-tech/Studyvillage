# 🌳 우리 학습마을 (Studyvillage)

교실에서 사용할 수 있는 학습 RPG 프로젝트입니다.

## 현재 버전

**v0.4.1 — Classroom SQLite Integration**

기본 운영 구조는 **교실 선생님 컴퓨터 = 서버**입니다.

- 선생님 컴퓨터에서 Node 서버 실행
- SQLite 파일에 학생 계정 및 기록 저장
- 학생 기기는 같은 학교 네트워크에서 선생님 컴퓨터로 접속
- 이름 + 비밀번호 로그인
- 비밀번호는 평문 저장하지 않고 `scrypt` 해시 + salt로 저장
- 로그인 세션 토큰으로 자기 기록만 수정 가능
- 퀴즈 종료 후 점수/도전 횟수/최고 점수/최근 점수를 SQLite에 저장
- 내 기록 화면을 열 때 서버에서 최신 기록 다시 불러오기
- 전체 랭킹 API 준비
- 서버가 없을 때만 브라우저 localStorage fallback

## 실행 파일

- `start-classroom.bat`: Windows에서 교실 서버 시작
- `server/server.js`: Express + SQLite 서버
- `server/package.json`: 서버 의존성
- `server/studyvillage.db`: 첫 서버 실행 시 자동 생성되는 학생 데이터 파일

## 첫 실행

현재 단계부터 **Node.js가 설치된 Windows 컴퓨터에서는 첫 실행 테스트가 가능합니다.**

1. 저장소 전체를 컴퓨터에 내려받습니다.
2. 루트 폴더의 `start-classroom.bat`을 더블클릭합니다.
3. 처음 한 번은 필요한 서버 구성 요소를 자동 설치합니다.
4. 서버 창에 선생님용 주소와 학생용 내부 네트워크 주소가 표시됩니다.
5. 선생님 컴퓨터에서는 `http://localhost:3000`으로 접속합니다.

아직 Node.js 없이 바로 켜지는 독립형 `.exe` 패키지는 아닙니다. 그 단계는 이후 교실용 패키징에서 진행합니다.

## 데이터 저장 위치

학생 계정과 게임 기록은 기본적으로 선생님 컴퓨터의 다음 파일에 저장됩니다.

`server/studyvillage.db`

따라서 이 파일을 백업하면 학생 기록도 함께 백업할 수 있습니다.
