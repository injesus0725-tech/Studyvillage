# 🌳 우리 학습마을 (Studyvillage)

교실에서 사용할 수 있는 학습 RPG 프로젝트입니다.

## 현재 버전

**v0.2.4 — Quiz Hall**

- 시작 화면
- 학습마을 광장
- 플레이어 캐릭터
- 방향키 / WASD 이동
- 모바일 화면용 방향 버튼
- PC와 태블릿 브라우저 대응
- 화면 경계 충돌
- 건물, 나무, 연못 충돌
- 도우미 선생님 NPC
- Space / 상호작용 버튼 대화
- 도전관 상호작용
- 객관식 퀴즈 3문제
- 정답/오답 피드백
- 문제별 100점 점수 계산
- 최종 결과 및 다시 도전

## 실행 방법

현재 소스 구조는 정적 웹앱 형태이며 `index.html`, `style.css`, `game.js`로 구성됩니다.
실행 확인 경로가 준비되는 즉시 별도로 안내합니다.
