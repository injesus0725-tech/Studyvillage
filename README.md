# 🌳 우리 학습마을 (Studyvillage)

교실에서 사용할 수 있는 학습 RPG 프로젝트입니다.

## 현재 버전

**v0.3.1 — Sync-ready Data Layer**

- 이름 + 비밀번호 기반 로컬 계정
- 비밀번호 평문 미저장
- 수수께끼 10문제 및 개인 기록판 유지
- 기록 데이터 구조 분리
- `data-service.js` 추가
- 이후 클라우드 저장소로 교체할 수 있는 어댑터 자리 마련

## 계정 구조

현재 `auth.js`는 같은 기기/브라우저에서 동작하는 임시 인증 단계입니다. 실제 여러 기기 공용 로그인에서는 서버 또는 인증 제공자로 교체합니다.

## 기록 구조

`data-service.js`가 플레이어 기록 저장 인터페이스를 담당하도록 분리했습니다.

- `totalScore`: 누적 점수
- `attempts`: 퀴즈 완료 횟수
- `bestScore`: 최고 점수
- `lastScore`: 최근 점수
- `updatedAt`: 마지막 기록 시각

현재 구현은 localStorage를 사용하지만, 동일한 함수 형태를 유지한 채 온라인 데이터베이스 어댑터로 교체할 수 있도록 설계합니다.

## 실행 상태

현재 소스는 정적 웹앱 형태입니다. 실제 접속 가능한 배포 경로가 확보되는 순간 별도로 안내합니다.
