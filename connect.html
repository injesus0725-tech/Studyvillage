  1. 상태 확인 — 아래 3개 항목이 모두 정상인지 확인합니다.

학교에서는 자동 추천이 항상 맞지 않을 수 있습니다. 학생 패드 한 대에서 열리는 주소를 고르면 이 PC에 선택값을 기억합니다.

다른 접속 주소 보기
활성 Wi-Fi 주소가 있으면 학생 패드와 같은 망일 가능성이 높아 먼저 추천합니다. 그래도 안 열리면 위 선택 메뉴에서 다른 주소를 직접 고르세요.

🛠 QR은 보이는데 학생 패드에서 안 열릴 때

  1. 위 주소 선택부터 바꾸기 — 자동 추천 QR이 안 열리면 다른 주소를 선택해 바로 새 QR을 사용합니다.
  2. 같은 학교망인지 확인 — 교사 PC와 학생 패드가 서로 통신 가능한 학교망에 있어야 합니다.
  3. 게스트망/분리망 확인 — 학교망이 기기끼리 통신을 차단하면 같은 학교 안에서도 접속되지 않습니다.
  4. Windows 방화벽 확인 — Studyvillage/Node/Electron의 사설 네트워크 접근을 허용합니다.
  5. 한 대로 먼저 시험 — QR 접속 → 로그인 → 활동 저장까지 확인한 뒤 전체 학생을 입장시킵니다.
Studyvillage · 자동 추천은 편의를 위한 기능입니다. 학교 네트워크에서는 직접 선택한 주소가 더 잘 연결될 수 있습니다.
