🧑‍🏫 수업 시작 4단계

  1. 상태 확인 — 아래 3개 항목이 모두 정상인지 확인합니다.
  2. QR 선택 — 먼저 추천 표시가 있는 QR을 학생 패드 한 대에서 시험합니다.
  3. 학생 입장 — 학생은 이름과 자기 비밀번호로 마을에 들어갑니다.
  4. 관리자 확인 — 수업 중에는 관리자 화면에서 참여·활동 기록을 확인할 수 있습니다.
⏳ 서버 상태 확인 중교실 서버 응답을 확인합니다.
⏳ 학생 기록 저장소 확인 중SQLite 저장 위치를 확인합니다.
⏳ 학생 접속 주소 확인 중같은 네트워크에서 사용할 주소를 찾습니다.
네트워크 주소를 찾고 있습니다...
추천 QR은 Wi-Fi/Ethernet과 사설 IP 여부 등을 기준으로 우선 표시합니다. 학교 네트워크 환경에 따라 추천 QR이 안 되면 아래 다른 QR도 그대로 사용할 수 있습니다.

🛠 QR은 보이는데 학생 패드에서 안 열릴 때

  1. 같은 학교망인지 확인 — 교사 PC가 유선이고 학생 패드가 Wi-Fi여도 괜찮습니다. 중요한 것은 학교 유선망과 Wi-Fi망 사이에서 기기끼리 통신할 수 있는지입니다.
  2. 게스트망/분리망 확인 — 학교망이 기기끼리 통신을 막는 구조라면 같은 학교 안에서도 접속이 안 될 수 있습니다. 이 경우 교내 IT 담당자에게 유선망과 Wi-Fi망 사이의 기기간 통신 허용 여부를 확인합니다.
  3. 다른 QR도 시도 — 추천 QR이 열리지 않으면 아래 대체 주소를 하나씩 시험합니다. 가상/VPN 어댑터는 보통 학생 접속용이 아닙니다.
  4. Windows 방화벽 확인 — 앱 첫 실행 때 네트워크 접근 허용 창이 뜨면 사설 네트워크 허용을 선택합니다. 차단했다면 Windows 방화벽에서 Studyvillage/Node/Electron의 사설 네트워크 접근을 허용합니다.
  5. 한 대로 먼저 시험 — 수업 시작 전에 학생 패드 한 대로 QR 접속 → 로그인 → 활동 저장까지 한 번 확인한 뒤 전체 학생을 입장시키면 가장 안전합니다.
Studyvillage · 서버와 저장소가 정상이어도 학교 네트워크가 유선망과 Wi-Fi망 사이 또는 학생 기기 사이의 통신을 차단하면 접속되지 않을 수 있습니다.
