🧑‍🏫 수업 시작 4단계

  1. 상태 확인 — 아래 3개 항목이 모두 정상인지 확인합니다.
  2. 주소 선택 — 목록에서 학생 패드와 같은 네트워크 주소를 선택합니다.
  3. 학생 입장 — 표시된 QR을 학생 패드로 촬영합니다.
  4. 관리자 확인 — 관리자 화면에서 참여·활동 기록을 확인합니다.
⏳ 서버 상태 확인 중교실 서버 응답을 확인합니다.
⏳ 학생 기록 저장소 확인 중SQLite 저장 위치를 확인합니다.
⏳ 학생 접속 주소 확인 중같은 네트워크에서 사용할 주소를 찾습니다.
네트워크 주소를 찾고 있습니다...
Windows가 현재 사용하는 Wi-Fi 또는 유선 주소를 우선 추천합니다. 추천 주소가 학생 패드에서 열리지 않으면 목록의 다른 주소를 선택해 시험하세요.

🛠 QR은 보이는데 학생 패드에서 안 열릴 때

  1. 같은 학교망인지 확인 — 교사 PC가 유선이고 학생 패드가 Wi-Fi여도 괜찮지만 두 망 사이의 통신이 허용되어야 합니다.
  2. 다른 QR도 시도 — 목록에서 Wi-Fi·이더넷 주소를 먼저 사용하고, 로컬 영역 연결이나 169.254 주소는 나중에 시험합니다.
  3. Windows 방화벽 확인 — Studyvillage의 사설 네트워크 접근을 허용합니다.
  4. 한 대로 먼저 시험 — QR 접속 → 로그인 → 활동 저장까지 확인한 뒤 전체 학생을 입장시킵니다.
